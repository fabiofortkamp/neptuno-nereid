# 0007. Public repository under AGPL-3.0

- Status: Accepted
- Date: 2026-11-25

## Context

The portfolio needs public code; the author may sell the app someday.

## Decision

The repository is **public from day one** under **AGPL-3.0**.

## Consequences

- Full visibility for the portfolio, with genuine open source.
- Anyone running a modified version as a service must publish their changes.
- As sole copyright holder, the author can relicense later. Outside
  contributions need a contributor agreement to keep that option.
